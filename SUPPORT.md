# Support

## Product access, accounts, and integrations

Contact [support@zyene.com](mailto:support@zyene.com) for LeadZen access, administrator invitations, account help, or approved integration questions.

Do not send passwords, API keys, mailbox credentials, customer data, or production database exports by email.

## Bugs and product requests

Use the GitHub [issue forms](../../issues/new/choose) for scrubbed, reproducible bug reports and feature requests. Remove names, email addresses, message contents, credentials, and any other sensitive details before posting.

## Security reports

For suspected vulnerabilities, follow [SECURITY.md](SECURITY.md). Do not report security issues in public GitHub issues.
